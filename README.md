# CYD Now Playing 릴리즈

CYD Now Playing 앱들의 빌드입니다. 각 앱이 이 저장소의 릴리즈를 확인해 새 버전으로 업데이트합니다.

| 앱 | 태그 | 파일 | 처음 설치 |
|---|---|---|---|
| Android | `android-vX.Y.Z` | `cyd-nowplaying-X.Y.Z.apk` | 휴대폰에서 APK를 받아 설치 |
| Mac | `mac-vX.Y.Z` | `cyd-nowplaying-mac-X.Y.Z.zip` | 풀어서 응용 프로그램 폴더로 옮긴 뒤 열기. 막히면 시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기 |
| Windows | `windows-vX.Y.Z` | `CYDNowPlaying-X.Y.Z.exe` | 원하는 폴더(예: `%LOCALAPPDATA%\Programs\CYDNowPlaying`)에 두고 실행. SmartScreen이 막으면 추가 정보 › 실행 |
| Shanling Q2 (Q2 Pod) | `q2-vX.Y.Z` | `q2-cydnp-vX.Y.Z.zip` | SD 카드 루트에 풀기 |

처음 한 번만 직접 설치하면 그다음부터는 앱이 알아서 업데이트합니다.
